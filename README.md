# TQ aka Turnquest Calculator

## Overview

TQ is a web application designed to assist engineering economy students in their studies. It provides a centralized platform for accessing formulas, performing calculations, and as a reference for effective revision and study sessions.

## Features

- **Formula Repository:** TQ offers a comprehensive collection of engineering economy formulas, categorized for easy navigation and reference.
- **Calculator:** Users can input variables into predefined formulas to quickly calculate results, aiding in problem-solving and comprehension.
- **Notes Reviews:** TQ facilitates collaborative note-taking and review sessions, allowing students to share insights, ask questions, and clarify doubts.

## Technical Details

TQ is built using modern web technologies for a seamless user experience and efficient development workflow:

- **Framework:** React with TypeScript
- **Build Tool:** Vite
- **UI Library:** Mantine UI

## Installation

To run TQ locally, follow these steps:

1. Clone the repository: `git clone https://github.com/unclebinary1001/tqcalculator.git`
2. Navigate to the project directory: `cd tqcalculator`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
5. Access TQ in your browser at `http://localhost:5173`
